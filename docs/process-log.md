проверка всех сценариев, скриншоты, коммиты, решение о стеке (Python для бэкенда).

## Этапы

### Этап 0. Планирование
- Инструмент: Claude
- Цель: понять задание и выбрать стек
- Промпт: ВСТАВЬТЕ свой первый запрос (загрузили текст задания, попросили собрать продукт по этапам)
- Результат: стек FastAPI + PostgreSQL + React/Vite, план этапов со скриншотами
- Моё решение: бэкенд на Python; идти маленькими шагами, каждый с подробным объяснением

### Этап 1. Среда и репозиторий
- Репозиторий создан вручную, склонирован, добавлены .gitignore и README
- Ошибка: `uvicorn: command not found`. Причина: не активировано виртуальное окружение; в Git Bash на Windows оно активируется `source .venv/Scripts/activate`
- Ошибка: Docker не смог скачать образ PostgreSQL (проблема с настройками прокси). Решение: установил PostgreSQL на компьютер
- Скриншоты: 01-…

### Этап 2. База данных и защита паролей
- Таблицы: users, student_profiles, staff_profiles (позже sessions)
- Пароли хранятся хешем Argon2id, одинаковые пароли дают разные хеши (соль)
- Ошибка: `bash: !': event not found`. Причина: Git Bash трактует `!` в двойных кавычках как команду. Решение: одинарные кавычки
- Тестовые аккаунты (вымышленные): student1, student2, dean

### Этап 3. Вход и сессии на сервере
- Реализовано: вход, выход, /me, блокировка на 15 минут после 5 неверных паролей, одинаковый ответ на неверный логин и пароль
- Проверено руками в Swagger: 401 без входа, 200 после входа, 204 на выходе, 429 при блокировке
- Кука sid: HttpOnly, SameSite=Lax. `document.cookie` её не показывает (скриншот)
- Промпт: ВСТАВЬТЕ формулировку запроса про вход и защиту

### Этап 4. Интерфейс
- React + Vite, страница входа, ошибки и состояния загрузки, адаптив от 360 px
- Ошибка: `Failed to resolve import "react-router-dom"`. Причина: библиотека не была установлена. Решение: `npm install react-router-dom`
- Ошибка в стилях от ИИ: синяя панель входа не растягивалась на всю высоту. Нашёл по скриншоту, исправил `align-content: stretch`
- Замечание по результату: главная страница была узкой карточкой. Попросил Claude заменить её полноценным каркасом: меню слева на компьютере, нижнее меню на телефоне
