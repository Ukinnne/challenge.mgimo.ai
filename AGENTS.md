# AGENTS.md — инструкция для ИИ-ассистентов

## Проект
«Деканат Next» — концепт личного кабинета студента («цифровой деканат будущего») для конкурса.
Это не официальный сервис вуза. Все данные вымышленные. Логотип свой, не вузовский.

## Стек
- Бэкенд: Python 3.10+, FastAPI, SQLAlchemy 2, PostgreSQL, Argon2 для паролей
- Фронтенд: React 18, Vite, React Router, чистый CSS (без UI-библиотек)
- Шрифт: Onest (лицензия OFL), подключён через npm, внешние CDN не используем

## Структура
```
backend/app/
  config.py      настройки из .env
  db.py          подключение к БД, сессии
  models.py      таблицы (SQLAlchemy)
  security.py    хеширование паролей, токены сессий
  deps.py        current_user, ApiError, COOKIE
  main.py        приложение, обработчики ошибок, /api/health
  init_db.py     создание таблиц (python -m app.init_db)
  seed.py        тестовые данные (python -m app.seed)
  routers/       адреса API по темам (auth.py, дальше schedule.py, grades.py, ...)
frontend/src/
  api.js         единая функция запросов к /api
  auth.jsx       хранилище входа (useAuth)
  App.jsx        маршруты
  components/    AppShell (меню), Logo, Icon
  pages/         Login, Home, Profile, ComingSoon, ...
  index.css      все стили и дизайн-токены (CSS-переменные в :root)
```

## Запуск (Windows, Git Bash)
```
# сервер, из папки backend
source .venv/Scripts/activate
uvicorn app.main:app --reload --port 3000

# сайт, из папки frontend
npm run dev        # http://localhost:5173, запросы /api уходят на :3000 через прокси
```
Тестовые аккаунты: student1 / Student1-Test!, student2 / Student2-Test!, dean / Dean-Test-2026!

## Правила безопасности (нарушать нельзя)
1. Пользователя определяем ТОЛЬКО по куке сессии `sid` через `Depends(current_user)`.
   Никакой адрес API не принимает id пользователя для доступа к личным данным.
2. Каждый запрос к личным данным (оценки, заявки, расписание) фильтруется по `user.id` из `current_user`.
3. Доступ по ролям (student / staff) проверяется на сервере, а не только скрытием пунктов меню.
4. Пароли только в виде Argon2id-хеша. В базе токены сессий только в виде SHA-256.
5. `password_hash` и токены никогда не попадают в ответы API.
6. Секреты только в `.env` (он в .gitignore). В коде и в браузере их нет.
7. Только вымышленные данные. Никаких реальных ФИО, номеров зачёток, логинов.
8. Ошибки API всегда в формате `{"error": "код"}`; интерфейс превращает код в человеческую фразу.

## Правила интерфейса
- Сначала телефон: всё должно работать от 360 px, без горизонтальной прокрутки.
- Цвета и размеры только через CSS-переменные из `:root`. Не вписывать цвета «в лоб».
- У каждого экрана есть состояния: загрузка, пусто, ошибка.
- Кнопки и пункты меню не меньше 44 px по высоте, виден фокус с клавиатуры (`:focus-visible`).
- Тексты интерфейса на русском, простые и без жаргона.
- Иконки рисуем сами (SVG в Icon.jsx). Внешние иконки и шрифты только с разрешающей лицензией.

## Как работать над проектом
1. Одна небольшая задача за раз. После каждой проверка руками и коммит.
2. Перед изменением модели данных обновить `models.py` и перезапустить `python -m app.init_db`.
3. Новые тестовые данные добавлять в `seed.py`, скрипт можно запускать повторно.
4. После значимого шага дописывать запись в `docs/process-log.md`.
